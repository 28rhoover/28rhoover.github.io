Welcome to my Website!

This page contains all of the projects developed in Q3 of my Intro to Programming class! Ranging from learning basic HTML to very amateur Javascript, these projects represent my re-entry into the basics of web development.

timePrison RMMZ Project — the main project

This is the culmination of all of my learning of RPG Maker MZ. Through challenges, I learned how to read flow charts with ease! Using RPG Maker in class has also ignited a spark within me, and in the future, I may pursue creating a fully-fleshed RPG of my own in the future!

Boxes

Made to educate me about how HTML box elements, "boxes.html" has served its purpose well. With colored elements corresponding to the functions of numerous built-in HTML elements, the colored divs provide a comprehensive and easy-to-understand representation on how HTML elements such as nav, article, and header work when used in tandem.

Flex

When created, flex.html was intended to demonstrate how the numerous flex attributes would appear when viewed on a webpage or better yet, a browser window of various sizes/resolutions. The flex.html website also demonstrates the relationship between parent and child flex elements, displaying the relationship between the two.

Javascript — the second best project

Used to demonstrate the most basic of Javascript through the creation of an extremely simple clicker/idle game, "javascript.html" adequately demonstrates the usefulness of Javascript when used in tandem with HTML. Though usually very useful for beginner Javascript developers, the entire project wasn't the most impactful project, due to me already having intermediate knowledge of Javascript. In fact, my very first experience with Javascript was when I made my first clicker game in 2022. Due to my (still limited) understanding of Javascript, and the fact I had decent knowledge on how to utilize Javascript to create a clicker game, the project wasn't the most significant in my eyes. None the less, the parts of the project where I had to make the upgrades increase in price depending on how many are already owned, and even more difficult, showing the upgraded price in the buying button, really sharpened my skills with if statements, as I actually had to use the "&&" Javascript operator for the first time in my life!
